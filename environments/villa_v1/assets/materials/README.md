# Material assets

The Summit Estate material library is entirely procedural and is generated by
`scripts/materials.py`. No third-party images, scans, texture maps, HDRIs, or
reference renders are copied into the materials.

The supplied villa reference PNGs are used only for visual interpretation and
must never be connected to shader nodes or redistributed as texture assets.

If a future revision adds external textures, only CC0/public-domain sources
may be stored here. Record the creator, asset title, direct source URL,
download date, and license URL in `LICENSES.md` before committing those files.
Keep physical dimensions or texel density notes beside each texture set so the
material's metre-scale controls remain meaningful.
